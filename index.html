Core Philosophy

The UNIX Way Meets Modern Machine Intelligence

AI belongs in user space, cleanly decoupled from PID 1. Rather than bloating the init system, syntropd adheres to the systemd modular architecture: small, isolated daemons with clearly bounded responsibilities communicating over standard Varlink sockets.

inferenced
/run/syntrop/io.syntrop.Inference1
ARBITER

Heterogeneous accelerator discovery and compute lease arbiter. Discovers DRM GPU, NPU, and CPU AMX/AVX-512 extensions. Governs memory pressure via cgroups v2 and preempts batch workloads during system emergencies.

  • Dynamic DRM render node discovery
  • Two-tier preemption (EmergencyTriage > Batch)
  • Kernel PSI pressure monitoring (CPU, I/O, VRAM)
  • Sealed memfd zero-copy tensor passing

modeld
/run/syntrop/io.syntrop.Model1
STORAGE

Content-Addressable Model Store under /var/lib/models. Deduplicates weights via filesystem reflinks, validates SHA-256 digests, and guarantees emergency triage models remain pinned in local storage.

  • SHA-256 CAS repository with tag aliases
  • Reflink deduplication on Btrfs/XFS/ZFS
  • Autonomous LRU cache quota management
  • Zero-eviction pinning for triage models

contextd
/run/syntrop/io.syntrop.Context1
CHRONOLOGY

Causality observer and configuration drift tracker. Observes unit drop-ins, package transactions (dnf/apt/pacman), and systemd journal events to correlate the exact chain of events leading to a failure.

  • fanotify / inotify tracking of /etc/systemd/system
  • Microsecond-precision causality ring buffer
  • Unified diff snapshotting before/after changes
  • Structured incident timeline extraction

toold
/run/syntrop/io.syntrop.Tool1
REMEDIATION

Sandboxed execution engine for safe diagnostic and remediating actions. Restricts tool execution using Linux Landlock LSM and seccomp filters, creating atomic filesystem snapshots before every mutation.

  • Strict execution allowlist & Polkit authentication
  • Landlock LSM unprivileged sandboxing
  • Automatic pre-execution rollback checkpoints
  • One-step deterministic remediation rollback

runtimed
/run/syntrop/io.syntrop.Runtime1
RUNTIME

Pure-Rust neural model inference and embedding engine. In-process token generation and embedding computation with zero dynamic C dependencies, lazy socket activation, and zero background idle memory.

  • GGUF model loader & token generation
  • 128-dim normalized semantic embeddings
  • DynamicUser unprivileged isolation
  • Socket-activated lifecycle with clean exit

routerd
/run/syntrop/io.syntrop.Router1 & 127.0.0.1:32768
ROUTER

Multi-provider LLM reverse proxy and dynamic scoring router. Distributes inference across local runtimed/inferenced instances, LAN Ollama clusters, and cloud providers with kernel PSI offloading and zero context contamination.

  • Dynamic candidate scoring (cost, throughput, context, tiers)
  • Kernel PSI telemetry loop & VRAM pressure offloading
  • Dual-stack TCP ingress (port 32768) & /run/syntrop/router.sock
  • Native Varlink IPC control socket (io.syntrop.Router1)
